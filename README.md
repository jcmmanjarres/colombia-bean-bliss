# Colombia Bean Bliss

Quiero una pagina web sobre temas relacionados con el café de Colombia, donde pueda poner historias, tipos de metodos de preparacion de cafe, variedades de cafe, de forma que las personas puedan visitar esta pagina y consultar temas relacionados al café, sera una pagina informativa sobre temas diversos del cafe que se iran actualizando con diferentes temas, podrias construir un prototipo del proyecto de una pagina modera, amigable, atractiva con temas relacionados al café
